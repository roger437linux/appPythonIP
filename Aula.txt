Obs.: Buildx funcionando, porém o builder atual (default) está usando o driver antigo docker, com recursos limitados.


1. Criar builder moderno

docker buildx create --name meu_builder --driver docker-container --use


2. Inicializar builder

docker buildx inspect --bootstrap


3. Verificar novamente

docker buildx ls

NAME/NODE          DRIVER/ENDPOINT                   STATUS    BUILDKIT         PLATFORMS
meu_builder*       docker-container
 \_ meu_builder0    \_ unix:///var/run/docker.sock   running   v0.29.0          linux/amd64, linux/amd64/v2, linux/amd64/v3, linux/386


4. Tornar builder padrão permanente

docker buildx use meu_builder


5. Ver builder ativo

docker buildx current


-----------------------------------------------------------


6. Logar no Docker hub

docker login


7. Criar imagem e enviar para o Docker hub
